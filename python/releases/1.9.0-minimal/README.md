# RF Map Viewer Python 1.9.0 Minimal

This release line preserves the compact Python/Tk viewer that shipped as
version 1.9.0 (build 10900). It is intentionally identified as **Minimal** so
that it is not confused with the full Python viewer restored in 1.9.1.

directory:

- Architecture: `arm64`

so they are replacement/rollback candidates and are not intended to be
installed side by side.
